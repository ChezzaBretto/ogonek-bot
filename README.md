# 🔥 TikTok Ogonyok Bot

Личный телеграм-бот, который сам продлевает «огоньки» (streak) в TikTok: каждую
ночь рассылает ❤️ в выбранные тобой чаты и, по желанию, автоматически отвечает
случайной фразой на присланные тебе видео.

Бот **личный** — работает только для своего владельца. Тот, кто развернул
проект у себя, подключает свой TikTok и пользуется ботом сам; посторонние люди
боту недоступны.

Автоматизация TikTok-веба — через [Playwright](https://playwright.dev/python/),
Telegram — через [python-telegram-bot](https://python-telegram-bot.org/).

> ⚠️ Проект учебный. Автоматизация TikTok может нарушать его правила — используй
> на свой страх и риск и только со своим аккаунтом.

## Возможности

- Ночная рассылка ❤️ по списку чатов (идемпотентно — дважды за сутки не шлёт).
- Подключение TikTok: скан QR из приложения **или** импорт cookies-файла.
- Автоответ на присланные видео случайной фразой из своего набора.
- Межпроцессный замок на браузер — на слабом VPS Chromium запускается строго
  по одному.

## Структура

| Файл | Назначение |
|------|------------|
| `bot.py` | Телеграм-бот: диалоги, кнопки, команды |
| `tt_core.py` | Ядро работы с TikTok-вебом (куки, браузер, чаты, отправка) |
| `runner.py` | Разовый прогон рассылки/проверки |
| `daily_run.py` | Ночной прогон (cron) |
| `retry_run.py` | Доборы в течение дня (cron) |
| `autoreply.py` / `autoreply_run.py` | Автоответ на видео (cron) |
| `qr_login.py` / `qr_session.sh` | Вход в TikTok по QR-коду |
| `notify.py` | Служебные сообщения владельцу из крон-скриптов |

Твои данные лежат в `users/<telegram_id>/` (`cookies.json`, `targets.txt`,
`profile.json` и т.д.) — эта папка **не** попадает в git.

## Установка

```bash
git clone <this-repo> tiktok-ogonek && cd tiktok-ogonek
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium        # при необходимости ещё: playwright install-deps

cp config.example.json config.json
# впиши токен от @BotFather; owner_id можно оставить пустым — владельцем станет
# тот, кто первым напишет боту /start, и его id запомнится
python bot.py
```

После запуска напиши боту `/start`, затем:
1. «🔗 Подключить TikTok» — отсканируй QR в приложении TikTok (или пришли файл
   сессии: команда `/cookies`).
2. «✏️ Задать список» — укажи, в какие чаты слать ❤️.

### Автозапуск и расписание (Linux)

- systemd: см. `tiktok-ogonek.service.example`.
- cron (пример; пути и интерпретатор подставь свои):

```cron
# рассылка в полночь, доборы днём, автоответ каждые 10 минут
0  0      * * *  /opt/tiktok-ogonek/.venv/bin/python /opt/tiktok-ogonek/daily_run.py
0  7,13,19 * * *  /opt/tiktok-ogonek/.venv/bin/python /opt/tiktok-ogonek/retry_run.py
*/10 * * * *  /opt/tiktok-ogonek/.venv/bin/python /opt/tiktok-ogonek/autoreply_run.py
```

> Расписание считается по локальной таймзоне сервера — выставь нужную через
> `timedatectl set-timezone ...`. Переменная `CRON_TZ` в cron на Ubuntu не
> работает.

## Если TikTok выкидывает сессию (другая страна)

TikTok привязывает сессию к стране, где она заведена. Если сервер в другой
стране, направь **только** трафик Playwright через SOCKS5-прокси/туннель в нужной
стране, а Telegram оставь напрямую. Задаётся переменной окружения:

```bash
export TT_PROXY=socks5://127.0.0.1:41080
```

Chromium не умеет SOCKS5 с логином/паролем — используй туннель без авторизации
(например `ssh -N -D 127.0.0.1:41080 user@host-в-нужной-стране`).

## Безопасность

- **Никогда не коммить `config.json` и папку `users/`** — там токен бота и
  cookies-сессия TikTok (полный доступ к аккаунту). Они уже в `.gitignore`.
- Если токен бота всё-таки утёк в git — отзови его у @BotFather и получи новый.
- cookies-файл = доступ к TikTok-аккаунту; бот сохраняет его с правами `600` и
  удаляет сообщение с файлом сразу после импорта.
